SKI-PORTFOLIO – ZWEITE VERSION

Die zweite Version verwendet dasselbe Grundgerüst und Design. Das Thema wurde auf
Skifahren geändert.

Dateien:
- index.html: Startseite
- thema.html: Hauptseite über dein Ski-Hobby
- kontakt.html: Kontaktformular
- style.css: gemeinsames Design
- Bilder/: hier deine sechs Ski-Fotos ablegen

Benenne deine sechs Bilder genau so:
Ski1.jpg
Ski2.jpg
Ski3.jpg
Ski4.jpg
Ski5.jpg
Ski6.jpg

Wichtig: Die Namen und Dateiendungen müssen exakt übereinstimmen. Wenn deine Fotos
z. B. .jpeg oder .JPG statt .jpg haben, passe die src-Angaben in index.html und
thema.html an. Der Ordner heißt "Bilder" mit großem B.

Lokal testen:
1. Öffne diesen Ordner in Visual Studio Code.
2. Rechtsklick auf index.html.
3. "Open with Live Server" auswählen.
4. Die Website öffnet sich im Browser.

Das Kontaktformular zeigt lokal eine Bestätigung an, versendet aber ohne Backend
keine echte E-Mail.
